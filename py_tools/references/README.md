# Reference data (read-only)

Vanilla Conquest of Elysium 5 v5.33 snapshots and extracted modding-manual material for lookup while editing Populum. Do not edit these files as part of mod changes — update `populum/populum.c5m` and Populum assets instead.

To refresh the extracted manual JSON after an Illwinter manual update, run from the repo root:

```bash
python py_tools/extract_modding_manual.py extract --command-index --refresh
```
